Timeweb Site Backups

A private automated website backup system for authorized website administrators.

Purpose

The application uses Rclone and Google Drive API to store website files, database backups and server configuration archives in an authorized Google Drive account.

Google Drive Access

The application is designed to use limited file-level permissions to create, verify and manage its own backup files.

This application is not a public service and is not affiliated with Timeweb or Google.
