Privacy Policy

Last updated: November 26, 2026

1. Application Purpose

Timeweb Site Backups is a private automated backup system for authorized website administrators.

2. Data Access

The application requests limited Google Drive permissions using the drive.file OAuth scope to create, read, verify and delete backup files associated with the application.

3. Data Usage

Google user data is used solely for authorized backup, maintenance and recovery operations. It is not used for advertising, profiling, analytics or artificial intelligence training.

4. Data Storage and Security

Backup archives are stored in the authorized Google Drive account. OAuth credentials are intended to be stored securely on the backup server with restricted access.

5. Data Sharing

The application does not sell Google user data. Access is limited to authorized administrators and necessary backup infrastructure providers.

6. Retention and Deletion

Backup files are retained according to the storage policy agreed with the account owner. Outdated backups may be automatically deleted. Users may also manually delete backup files.

7. Revoking Access

Users may revoke the application's access at any time through their Google Account security settings.

8. Google API Compliance

The application is intended to comply with the Google API Services User Data Policy, including the Limited Use requirements.

9. Contact

For privacy or data deletion requests, contact the application administrator using the support email provided on the Google OAuth consent screen.
